# 🌊 DIVE 2024 해커톤 - DRF 백엔드 프로젝트

> **무박 3일 동안 진행된 DIVE 2024 해커톤에서 개발한 Django REST Framework 기반 백엔드 API 서버입니다.**  
> 본 레포는 백엔드 전용 코드로 구성되어 있으며, 사용자 관리, 조사 및 정리 데이터 기록, 관리자 기능 등을 포함하고 있습니다.  
> **KIOST × (사)동아시아바다공동체 오션 해커톤 - 오션 트랙 3등 수상작**  
> **행사 개최지: 부산광역시**

---

## 프로젝트 개요

- **대회명**: 제 1회 DIVE 2024 해커톤
- **주요 기능**:
  - 사용자 회원가입 / 로그인 (JWT 기반 인증)
  - 관리자 전용 회원 생성 / 목록 / 삭제
  - 조사(investigation) / 환경정리(cleanup) 데이터 등록
  - 운전자(driver) 기록 저장
  - 엑셀 데이터 DB 업로드 스크립트 제공

---

## 기술 스택

| 항목 | 사용 기술 |
|------|-----------|
| Framework | Django 4.2, Django REST Framework |
| Auth | JWT (`SimpleJWT`) |
| Docs | Swagger (`drf_yasg`) |
| DB | SQLite3 (개발용) |
| 기타 | CORS 설정, 커스텀 유저 모델 |

---

## 프로젝트 구조

```
.
├── users/               # 사용자 인증, 커스텀 유저 모델
├── manager/             # 관리자 전용 기능 (회원 등록/삭제 등)
├── investigation/       # 조사 관련 기능
├── cleanup/             # 환경정리 관련 기능
├── driver/              # 운전자 정보 기록
├── common/              # 공통 로직
├── ocean/               # 프로젝트 설정
├── import_*.py          # 엑셀 데이터 → DB 업로드 스크립트
└── ...
```
